# mockups

Клікабельні UI-мокапи (демо-дані, без реальних клієнтів).

## sheet/ — застосунок «Чистий аркуш» (PWA)

Нотатки на чистому аркуші: кілька нотаток, панель зі списком, пошук по назві й повнотекстовий, автозбереження. Дані лежать лише в localStorage цього пристрою (поки без синхронізації). Тема, сітка і правопис — спільні для всіх нотаток. Встановлюється як застосунок (manifest + service worker), працює без мережі.

- `sheet/index.html` — застосунок; `manifest.webmanifest`, `sw.js`, іконки.
- Публікація: GitHub Pages уже збирає весь репозиторій з гілки `main` (як і решту мокапів), тож застосунок живе за адресою `https://yokogamma.github.io/mockups/sheet/` — окремий workflow не потрібен.
- Локально: `python3 -m http.server 8765 --directory sheet` і відкрити `http://localhost:8765/` (service worker працює лише по http(s), не з file://).
- Старий одноаркушевий мокап `freeform-editor-mockup.html` лишається як демо; його аркуш із localStorage автоматично стає першою нотаткою застосунку.

## Мокапи

- net-pickup-mockup.html — misce.top OneLink, сторінка отримання замовлення сіток (моб., світла, теплі тони): склад, точка видачі + графік, схема проходу, приватний блок «де залишено + код», кнопка «Я забрав» деактивує посилання.
- booking-cabin-mockup.html — картка бронювання будиночка «Садиба Гірська» (моб., світла, теплі тони): ілюстроване «фото» будиночка, особиста фраза «час відпочинку», дати/оплата, міні-галерея житла, додаткові послуги, презент від власника, як доїхати, контакти, приватний блок Wi-Fi/ключ.
- onelink-pass-mockup.html — рання об'єднана версія OneLink (3 екрани: замовлення + бронювання + конструктор в адмінці з шаблонами, блоками-перемикачами, терміном дії та генерацією лінка + QR).
- courier-delivery-map.html — адресна доставка по Києву: реальна карта (Leaflet/OSM), мульти-курʼєр (резерв/блокування), сегмент «Спільна ↔ Моя», 4 стадії, дизайн дашборда /courier.
- courier-delivery-mockup.html — рання версія (список + схематична карта).

- freeform-editor-mockup.html — порожній редактор у стилі Notion, «чистий альбомний аркуш»: клік у будь-якому місці екрана створює текст саме там (а не з лівого краю), блок займає весь вільний простір до правого краю, ручка ⋮⋮ при наведенні перетягує фразу (миша + тач), текст прилипає до сітки точок (рядок між двома рядами, початок тексту на стовпчику точок, крок сітки = висота рядка = 1.5 × кегль); блоки не накладаються: ширина рахується до сусіда праворуч, те, що під блоком, зсувається вниз на цілі ряди (і при дропі, і коли текст підростає), а якщо до сусіда праворуч менше за мінімальну ширину — контур червоний і дроп скасовується; при ресайзі колонки складаються у стовпчик; точки лише в робочому полі — по краях чисте поле щонайменше в клітинку, де блок не може стояти; автозбереження в localStorage; три теми по колу — світла, темна, пісок/папірус (з ледь помітною фактурою паперу), у кожної свій контраст точок; перевірку правопису можна вимкнути/увімкнути кнопкою в шапці (типово вимкнена, вибір запамʼятовується).
- freeform-editor-practices.html — анімовані приклади до «чистого аркуша»: що робити, коли блоки накладаються. Пʼять сцен на тій самій сітці, курсор рухається сам: вільне накладання (шари), виштовхування сусідів, заборона дропу з червоним контуром, ширина до сусіда («обтікання» прямокутниками), звуження вікна з колонок у стовпчик.
