# mockups

Клікабельні UI-мокапи (демо-дані, без реальних клієнтів).

- onelink-pass-mockup.html — misce.top OneLink: одноразові короткі посилання (моб. версія). Три екрани: сторінка отримання замовлення сіток (склад, точка видачі, графік, схема проходу, приватний блок «де залишено + код»), картка бронювання будиночка (дати, оплата, як доїхати, контакти, Wi-Fi/ключ) і конструктор в адмінці (шаблони, блоки-перемикачі, термін дії, генерація короткого лінка + QR).
- courier-delivery-map.html — адресна доставка по Києву: реальна карта (Leaflet/OSM), мульти-курʼєр (резерв/блокування), сегмент «Спільна ↔ Моя», 4 стадії, дизайн дашборда /courier.
- courier-delivery-mockup.html — рання версія (список + схематична карта).
